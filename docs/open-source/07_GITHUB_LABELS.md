# GitHub Labels

We use labels to organize our work effectively:

- `good first issue`: Ideal for new contributors. Usually a self-contained AST rule or a documentation fix.
- `bug: false positive`: The analyzer flagged something it shouldn't have.
- `bug: false negative`: The analyzer missed something it should have caught.
- `enhancement: new rule`: Request to detect a new performance anti-pattern.
- `enhancement: recipe`: Request to add an automated fix recipe for an existing diagnostic.
- `core: engine`: Relates to the core AST parsing infrastructure.
- `core: mcp`: Relates to IDE integration and the Model Context Protocol.
