# Community Guidelines

We strive to create an inclusive and respectful environment.

1. **Be Respectful**: Disagreements happen, especially on performance topics. Debate the code, not the person.
2. **Be Constructive**: "This rule is stupid" is not helpful. "This rule triggers a false positive on X pattern, here is a reproduction" is immensely helpful.
3. **No Harassment**: Any form of harassment will result in an immediate ban.
