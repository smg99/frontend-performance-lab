# Public Repository Checklist

- [x] **README.md**: Crisp value proposition, clear installation instructions, CI status badges.
- [x] **LICENSE**: An open-source license is present at the root (MIT/Apache 2.0).
- [x] **CODE_OF_CONDUCT.md**: Expectations for contributor behavior are clearly defined.
- [x] **CONTRIBUTING.md**: Guidelines for setting up the repo locally, running tests, and submitting PRs.
- [x] **SECURITY.md**: Instructions for reporting vulnerabilities safely.
- [x] **SUPPORTED_IDES.md**: Documented configurations for all supported editor environments.
- [x] **ROADMAP.md**: Clear vision of upcoming phases (e.g., Recipe Mapping, New Rules).
- [x] **CHANGELOG.md**: Standardized version history.
- [x] **RELEASE_NOTES.md**: Public-facing summaries of major updates.
- [x] **Issue Templates**: `.github/ISSUE_TEMPLATE/` populated with Bug Report, Feature Request, and Question templates.
- [x] **PR Template**: `.github/PULL_REQUEST_TEMPLATE.md` to standardize code submissions.
- [x] **CODEOWNERS**: Defines core maintainers for PR reviews.
- [x] **FUNDING.yml**: Optional tipping/sponsorship metadata.
- [x] **GitHub Actions CI/CD**: Workflows in `.github/workflows/` for testing, linting, code quality, and automated releases.
