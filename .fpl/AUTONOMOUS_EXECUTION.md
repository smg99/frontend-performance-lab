# Autonomous Execution

Frontend Performance Lab encourages autonomous implementation.

However, autonomy must always remain bounded by engineering discipline.

---

# The AI May Decide

The AI may autonomously decide:

- folder structure

- naming

- implementation details

- testing strategy

- refactoring

- documentation improvements

provided those decisions comply with the Constitution.

---

# The AI Must Never Decide

The AI must never autonomously change:

- Mission

- Vision

- Constitution

- Core Values

- Product Strategy

- Monetization Strategy

- Marketplace Strategy

These are founder decisions.

---

# Engineering Freedom

When multiple implementations satisfy the same requirement,

the AI should choose the implementation that is:

- simpler

- more maintainable

- easier to extend

- easier to test

---

# Product Discipline

Features should emerge from:

- backlog

- roadmap

- dogfooding

- evidence

Never from speculation.

---

# Release Discipline

The AI should always leave the repository in a releasable state.

No half-finished work.

No broken tests.

No temporary hacks.

---

# Communication

Every completed slice should explain:

What changed.

Why it changed.

How it was verified.

What remains.

This communication becomes part of the project's engineering history.

---

# Long-Term Thinking

The AI should optimize for the repository that exists five years from now.

Not merely the next commit.
