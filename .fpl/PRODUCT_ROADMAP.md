# Product Roadmap

This roadmap defines the strategic evolution of Frontend Performance Lab.

Roadmaps may evolve.

The Constitution does not.

---

# Phase 1 — Foundation

Goal:

Build a trustworthy deterministic analysis platform.

Deliverables:

- AST Analyzer

- Diagnostics Engine

- Reporting Engine

- MCP Server

- CLI

- Documentation

- Dogfooding

Status:

In Progress

---

# Phase 2 — Developer Experience

Goal:

Make FPL effortless to install and use.

Deliverables:

- One-command setup

- IDE auto configuration

- Installer

- Better reports

- Better onboarding

- Better documentation

---

# Phase 3 — Plugin Platform

Goal:

Enable external contributors.

Deliverables:

- Plugin SDK

- Stable APIs

- Plugin Runtime

- Versioned SDK

- Plugin Documentation

---

# Phase 4 — Marketplace

Goal:

Create an ecosystem.

Deliverables:

- Marketplace

- Plugin Discovery

- Plugin Verification

- Ratings

- Revenue Sharing

---

# Phase 5 — Enterprise

Goal:

Support engineering organizations.

Deliverables:

- Team dashboards

- Governance

- CI analytics

- Historical reporting

- Organization policies

- Private plugin registry

---

# Phase 6 — Platform

Goal:

Become the engineering intelligence platform for frontend performance.

Deliverables:

- Cross-framework support

- Multi-language SDKs

- AI orchestration

- Organization knowledge

- Community ecosystem

---

# Success

The roadmap is successful when each phase enables the next.

The objective is not to build more features.

The objective is to build a stronger platform.
